# 道源符體 · 法本

符籙風格中文字體的展示頁。輸入文字，挑法式與紙色，即時排成符紙，可存成 PNG。

**線上版：https://ziv50109.github.io/daoist-sigi/**

字體又稱雨君鬼臣體，思源黑體的衍生字體，把道教符籙的筆畫元素接在漢字字形上。

## 功能

- **法式**：立符（直排）／橫符（橫排）
- **朱印**：硃砂、墨、金、素
- **紙**：黃籙、宣紙、墨底
- **法印**：敕令、敕雷令、急急如律令、無
- **字級／行距／字距**滑桿即時調整
- **缺字偵測**：同一個字用「符體＋備援」與「純備援」各畫進 canvas 比對像素，字集沒收的字會標出來並退回系統字體
- **下載 PNG**：符紙連暗紋、法印一起輸出
- **字表**：列出目前字集實際涵蓋的字

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 單檔頁面，樣式與邏輯全部內嵌，另含 513 字精簡字集（base64） |
| `sigi.woff2` | 完整 8,231 字字集 |
| `.nojekyll` | 停用 GitHub Pages 的 Jekyll 處理 |

## 字體載入

`index.html` 裡的 `FONT_URL` 指向同目錄的 `sigi.woff2`。頁面先用內嵌的 513 字精簡字集渲染，完整字集下載完成後換上；下載失敗則整頁留在精簡字集，功能不受影響。

`FontFace` 一律以 anonymous CORS 模式取檔，所以：

- head 裡的 `<link rel="preload">` 必須帶 `crossorigin`，少了它字體會被下載兩次
- 把 `FONT_URL` 換到別的網域（CDN）時，該來源必須回 CORS 標頭

## 本機預覽

```bash
python3 -m http.server 8000
# → http://127.0.0.1:8000/
```

用 `file://` 直接開會載不到 `sigi.woff2`（opaque origin 過不了 CORS），頁面會退回精簡字集。
